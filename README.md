# 🚀 ConfigFars Escape Pod
### فرار از محدودیت‌های کانتینر و سرویس‌های ابری

---

## 💡 ایده اصلی

تا به حال پیش آمده که روی یک کانتینر Docker یا هر سرویس ابری محدود شده‌ای، کار کنید و به دیواره‌های سخت‌افزاری یا نرم‌افزاری برخورد کنید؟  
مثل زمانی که `sudo` را قطع کرده‌اند یا دسترسی به `root` ندارید.

**راه حل:** یک اسکریپت سبک، امن و قدرتمند برای دور زدن این محدودیت‌ها و دسترسی کامل به سیستمعامل میزبان.

> ✅ این اسکریپت **متن‌باز** (Open Source) است و تحت **لایسنس MIT** منتشر شده است.  
> ✅ تیم **ConfigFars** با هدف افزایش آزادی عمل کاربران در محیط‌های مجازی، این ابزار را طراحی کرده است.

---

## 🔥 امکانات کلیدی

| ویژگی | توضیح |
|-------|-------|
| 🛡️ **امنیت بالا** | بدون استفاده از باگ‌های هسته یا اکسپلویت‌های خطرناک |
| 👑 **دسترسی روت کامل** | معادل دسترسی `root` روی میزبان |
| 📁 **دسترسی کامل به فایل‌سیستم** | امکان Mount، Edit و Execute هر فایلی |
| 🔄 **قابل اجرا در همه‌جا** | روی اکثر توزیع‌های لینوکس و حتی WSL2 کار می‌کند |
